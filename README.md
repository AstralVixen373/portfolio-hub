# Web Development Portfolio

## Overview

This portfolio is a collection of projects built as part of a web development learning journey. It demonstrates progressive skills in frontend development, backend fundamentals, and interactive application design.

The goal of this portfolio is to showcase practical experience in building real-world web applications, with a focus on clean code, user experience, and functional features.

## Projects

The portfolio will include three main projects developed in stages:

- A JavaScript-based web application for writers, focused on DOM manipulation and state management
- A Ruby on Rails habit tracker and wellbeing application introducing backend architecture and database-driven development
- A React-based visual novel game project exploring component-driven UI and interactive user experiences

Each project will build on the previous one, gradually increasing in complexity and technical depth.

## Tech Stack
- HTML5

- JavaScript
- Ruby on Rails
- React
- Git & GitHub

## Purpose
This portfolio was created to:

- Showcase practical coding ability
